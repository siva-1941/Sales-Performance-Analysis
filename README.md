# 📊 Sales Performance Analysis Dashboard | Power BI

## 📌 Project Overview
This Power BI project analyzes sales performance, profitability, customer trends, and regional performance using Superstore sales data.

The dashboard provides interactive business insights through data visualization, forecasting, time intelligence analysis, KPI tracking, and drill-down reporting to support data-driven decision making.

---

# 🛠️ Tools & Technologies Used

- Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Excel / CSV
- MySQL
- Data Cleaning & Transformation
- Data Visualization

---

# 📊 Dashboard Features

✅ Interactive KPI Cards  
✅ Dynamic Titles  
✅ Drill-Down Analysis  
✅ Time Intelligence Analysis  
✅ Running Total Analysis  
✅ Sales Forecasting  
✅ Sales Growth % & Profit Growth %  
✅ Regional & Category Analysis  
✅ Tooltip Page  
✅ Business Insights & Recommendations  
✅ Interactive Filters & Slicers  

---

# 📈 Key Business Insights

- Technology category generated the highest overall sales revenue
- Certain regions consistently outperformed others in profit contribution
- Seasonal sales trends revealed peak sales periods during specific months
- Some high-sales products showed lower profit margins
- Forecast analysis indicates future business growth opportunities

---

# 💡 Business Recommendations

- Increase focus on high-performing product categories
- Optimize pricing strategies for low-margin products
- Expand marketing efforts in high-performing regions
- Use forecasting insights for inventory and resource planning
- Implement customer retention strategies for valuable customers
